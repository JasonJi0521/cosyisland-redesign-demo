# COSY ISLAND Redesign Demo

A mobile-first redesign concept for COSY ISLAND. The page includes a simple
Chinese before/after switch, a premium storefront, product quick view, and an
interactive AI fit recommendation flow.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production build is published from the `gh-pages` branch.
